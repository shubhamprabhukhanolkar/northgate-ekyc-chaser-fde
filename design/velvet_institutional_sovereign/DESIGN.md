## Brand & Style
The design system establishes a high-trust, elite relationship manager (RM) workspace tailored for high-stakes corporate onboarding, AML remediation, and eKYC document verification. Inspired by the sleek, frictionless precision of Web3 wallet interfaces and sovereign custody tools, this aesthetic blends institutional gravitas with hyper-refined digital-first fluidity.

Key characteristics:
- **Design Philosophy**: Deep Institutional Minimalism fused with Soft Luminous Accents. The dark mode evokes an executive, terminal-grade cockpit, while the companion light mode offers an airy, compliance-certified corporate audit environment.
- **Atmosphere & Tone**: Focused, hyper-organized, friction-free, and calming under compliance pressure. It replaces bureaucratic fatigue with effortless operational clarity.
- **Visual Stance**: Ultra-spacious container geometries, delicate hairline border definition (0.5px–1px), glowing semantic badges, pill-shaped tactile controls, and high-legibility monospace callouts for audit-grade data points.

## Colors
The palette balances institutional calm with high-visibility audit statuses:

- **Primary Accent (`#AB9FF2` / Phantom Lavender)**: Reserved for primary action levers, active navigation states, selected corporate entities, and signature actions. It cuts through deep surfaces with soft, non-fatiguing luminance.
- **Secondary Tone (`#3C315B` / Deep Plum Tint)**: Used for soft container backdrops, contextual highlights, active tab fills, and hover envelopes around lavender interactive items.
- **Tertiary & Semantic Signals**:
  - `status-verified` (`#2EC08B` / Phantom Mint): Affirms verified documents, cleared eKYC thresholds, and compliant UBO structures.
  - `status-nudge` (`#F59E0B` / Amber Nudge): Designates expiring verifications, automated reminder triggers, and partial doc submissions.
  - `status-alert` (`#FB7185` / Soft Coral): Commands urgent attention for rejected signatures, sanction hits, or missing constitutive deeds.
- **Neutral Surface Foundation**:
  - Dark Canvas (`#111114`): Deep void background suppressing glare during prolonged RM shifts.
  - Elevated Surfaces (`#1C1C21`): Micro-cards, modal drawers, and side panels.
  - Structure Lines (`rgba(255, 255, 255, 0.07)`): Feather-light separation that removes visual heaviness.
- **Light Corporate Alternative**: When operating in strict daylight corporate environments, `#F8FAFC` anchors the canvas with `#FFFFFF` panels, `#E2E8F0` hairline rules, and deep corporate trust signals guided by `#2563EB` Cobalt and `#0D9488` Teal.

## Typography
Typography reflects high-trust institutional reporting with absolute typographic discipline:

- **Headlines (`Plus Jakarta Sans`)**: Delivers friendly authority, balanced geometry, and modern rounded terminals. Used across workspace module headers, corporate account names, and drawer titles.
- **Body & Data Content (`Inter`)**: Neutral, ultra-legible, utilitarian standard. Handles case notes, compliance justifications, document rejection explanations, and multi-line communication drafts.
- **Audit & Figures (`JetBrains Mono`)**: Strict, monospaced tabular alignment for LEI numbers, Case UUIDs, document hashes, swift timestamps, and multi-currency transaction thresholds. Prevents eye-tracking misalignment during rapid scanning.

## Layout & Spacing
The layout model operates as an executive, desktop-first workspace with generous operational breathing room:

- **Grid System**: 12-column fluid grid system bounded by a max viewport container of `1720px`. The standard configuration supports a persistent collapsible 72px/260px navigation rail, a 420px contextual KYC chase queue, and an expansive 8-column case dossier workspace.
- **Card Padding**: Internal card space is uncommonly spacious (`24px` to `32px` / `space-lg` to `space-2xl`), eliminating the claustrophobic clutter typical of legacy banking mainframes.
- **Reflow & Responsive Adaptations**:
  - **Desktop (>1440px)**: 3-pane unified layout (Navigation + Queue List + Active Case Canvas & Chaser Log).
  - **Tablet/Small Desktop (1024px - 1439px)**: Queue transitions into a floating off-canvas sliding drawer; primary workspace holds the 12-column span with `1.5rem` gutters.
  - **Mobile (<1024px)**: Single-column linear flow prioritizing immediate one-tap nudge dispatches and document verification overrides.

## Elevation & Depth
Elevation is achieved using translucent tonal layering combined with hair-thin luminous boundaries, avoiding heavy drop shadows:

- **Layer 0 (Canvas Base)**: Solid `#111114`, non-reflective foundation.
- **Layer 1 (Card & Section Containers)**: `#1C1C21` with a `1px` continuous border composed of `rgba(255, 255, 255, 0.07)`.
- **Layer 2 (Hover & Context Panels)**: Subtle dark gradient shifts toward `#24242B`, accompanied by a faint top-edge highlight (`rgba(255, 255, 255, 0.12)`).
- **Layer 3 (Modals, Popovers, & Document Viewers)**: Deep `#1C1C21` surface backed by a `24px` backdrop blur (`backdrop-filter: blur(24px); background-color: rgba(28, 28, 33, 0.85);`), bounded by `rgba(171, 159, 242, 0.18)` on active or dragged states.
- **Ambient Shadow**: Shadows are ultra-diffuse and tinted: `0 12px 36px -8px rgba(0, 0, 0, 0.65)`.

## Shapes
The shape language uses expansive, gentle curves to break away from traditional enterprise rigidity:

- **Cards and Major Panels**: Shaped with `rounded-xl` (24px corner radius) to project an open, non-aggressive modular presence.
- **Interactive Badges, Search Bars, and Buttons**: Pure pill architecture (`border-radius: 9999px`) provides tactile certainty and soft-touch interaction.
- **Inner Controls (Inputs, Dropdowns, Checkboxes)**: Anchored by `rounded-md` (8px–12px) to maintain structured optical alignment alongside dense text fields.

## Components

### Buttons
- **Primary Action (Chase Document / Approve)**: Pill-shaped (`9999px`), background `#AB9FF2`, text `#111114` (semi-bold `label-ui`), 0 0 20px rgba(171, 159, 242, 0.25) ambient glow on hover.
- **Secondary (Custom Nudge Template)**: Pill-shaped, background `rgba(255, 255, 255, 0.05)`, border `1px solid rgba(255, 255, 255, 0.1)`, text `#FFFFFF`. Hover triggers background `#3C315B` and border `rgba(171, 159, 242, 0.4)`.
- **Destructive / Flag Risk**: Pill-shaped, background `rgba(251, 113, 133, 0.1)`, border `1px solid rgba(251, 113, 133, 0.3)`, text `#FB7185`.

### Chips & Badges
- **Status Pills**: Height `26px`, padding `0 12px`, typography `label-code-sm`.
  - *Missing/Overdue*: Coral background (`rgba(251, 113, 133, 0.12)`), text `#FB7185`, pulsating `6px` circular dot.
  - *Pending Validation*: Amber background (`rgba(245, 158, 11, 0.12)`), text `#F59E0B`.
  - *eKYC Verified*: Mint background (`rgba(46, 192, 139, 0.12)`), text `#2EC08B`.
  - *Case Tier / LEI*: Neutral slate background (`rgba(255, 255, 255, 0.06)`), text `#9E9EA8`.

### Input Fields & Search
- **Container**: Height `48px`, background `rgba(255, 255, 255, 0.03)`, border `1px solid rgba(255, 255, 255, 0.08)`, radius `12px`.
- **States**: Focused state transitions border to `#AB9FF2` with a `0 0 0 3px rgba(171, 159, 242, 0.15)` aura.
- **Integrated Actions**: Integrated mono quick-key badge (e.g., `⌘K`) formatted with `label-code-sm`.

### Checkboxes & Verification Radios
- Size `20px`, radius `6px` (or circular pill for radio). Checkbox idle state has a `1px` border of `rgba(255, 255, 255, 0.2)`. Checked state transitions to full `#2EC08B` with high-contrast `#111114` check icon.

### Cards & Dossier Panels
- **Container Specs**: Background `#1C1C21`, radius `24px`, padding `28px`, border `1px solid rgba(255, 255, 255, 0.07)`.
- **Sub-sections**: Inner nested document tiles use `#151518` background, `16px` radius, and `16px` padding to structure UBO trees and corporate registry attachments.

### Specialized Workspace Components
- **Missing-Document Chaser Timeline**: Vertical continuous timeline line (`1px` width, `rgba(255, 255, 255, 0.08)`) with pill-shaped checkpoint nodes tracking multi-channel automated triggers (Email, WhatsApp Sovereign Portal, RM Direct Call).
- **Audit-Grade Document Viewer Bar**: Top-anchored floating dock with JetBrains Mono hash stamp, metadata zoom tools, and rapid toggle buttons for "Certify Legibility" vs "Issue Rejection Protocol".
